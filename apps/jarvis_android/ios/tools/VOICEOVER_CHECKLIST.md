# JARVIS · VoiceOver 走查清单

在真机上走一遍，约 20 分钟。每一项只回答一件事：**VoiceOver 读出来的话，对一个看不见屏幕的人够不够用。** 发现的问题记下“页面 + 哪个控件 + 读成了什么”，我据此修。

## 开启与基本手势

- 开启：设置 → 辅助功能 → VoiceOver（或对 Siri 说“打开旁白”）。建议在“辅助功能快捷键”里设成三击侧边键开关。
- 向右轻扫 / 向左轻扫：下一个 / 上一个元素。双击：激活。三指上下滑：滚动。双指搓动（Z 字）：返回。
- iPhone Duo 另外要试：内屏横放（左侧会话列表常驻）、内屏竖放（顶部栏）、外屏。

## 走查前我已经查过的（代码层面）

- 弹出的对话框、菜单、重命名框会把焦点移到标题或输入框（`screenChanged`）。
- 登录页的错误提示会播报（`announcement`）。
- 长按会话行的菜单每一项是单独的无障碍元素，带“删除”这类操作的语义。
- 通话页 17 处、消息行 11 处标注，控件名称都有。

## 逐页检查

### 1. 登录页
- [ ] 用户名、密码、登录按钮读法清楚（说的是“用户名”而不是“文本框”）。
- [ ] 填错后，错误文字被自动读出来，不用自己再扫一遍。
- [ ] 钥匙串 / 面容登录按钮读成“使用面容 ID 登录”一类，不是“按钮”。

### 2. 主页（没有消息时）
- [ ] 欢迎页的四张卡片，每张读出标题和说明，并且是“按钮”。
- [ ] 顶部三个按钮：会话列表、新建、更多——各自读出名字。

### 3. 对话页
- [ ] 每条消息读出“谁说的”（你 / JARVIS），再读内容。
- [ ] 回复正在生成时：不会一个字一个字地吵；生成完成有一次提示（**这一项代码里没有专门处理，重点看**）。
- [ ] 代码块、表格、图片：图片读出“图片”并能双击打开大图；代码块读出语言。
- [ ] “思考”折叠块：读出展开 / 收起状态。
- [ ] 复制、重新生成两个小图标：名字是“复制回复”“重新生成”。
- [ ] 输入框：读“发送消息”；右侧按钮在“麦克风”和“发送”之间切换时，名字跟着变。
- [ ] “+”（附件）和“思考”菜单：读得出当前选择（如“思考 高”）。

### 4. 会话列表（抽屉，或内屏横放时常驻）
- [ ] 每一行读出标题，当前打开的那条读出“已选中”。
- [ ] 分组标题（今天 / 昨天 / 更早）被当作标题，可以用转子“标题”快速跳。
- [ ] 长按一行（或用转子里的“操作”）：能打开重命名 / 删除菜单。
- [ ] 内屏横放时，列表和对话两块区域的焦点顺序：先列表，后对话，符合从左到右。
- [ ] 常驻列表的折叠把手（左缘细条）：读出“收起 / 展开会话列表”，双击能切换。

### 5. 作品
- [ ] 对话中作品生成完成后，作品面板自动升起：**VoiceOver 下有没有被告知**（代码里没有专门播报，重点看）。
- [ ] 作品大图查看：读出“关闭 / 分享 / 下载”，双指捏合缩放可用。
- [ ] 加载失败时读出“图片无法载入”和“重试”。

### 6. 设置各页、模型状态页
- [ ] 每个设置行读出名称 + 当前值（如“消息字号 ，标准”）。
- [ ] 开关读出开 / 关。
- [ ] **模型状态页**：这一页几乎没有专门的无障碍标注，是风险最大的一页——逐行听，看“状态圆点、延迟数字”有没有被读成“图像”或者没读。
- [ ] 返回：双指 Z 字搓动能退回上一页。

### 7. 通话页
- [ ] 语音 / 视频切换、静音、挂断：名称和状态（“已静音”）清楚。
- [ ] 通话中状态变化（连接中 → 已连接 → 断开）有播报。
- [ ] 竖放时顶部栏版面的控件焦点顺序正确。

### 8. 对话框与菜单
- [ ] 删除确认、重命名、提示框：打开时焦点在标题或输入框上，焦点出不去背后的页面。
- [ ] 取消和确认按钮都读得出，破坏性的那个读出“删除”二字。

## 同时检查

- 设置 → 辅助功能 → 显示与文字大小 → 更大字体：拉到最大两档，看输入框、会话行、作品面板有没有被截掉。
- 开启“减弱动态效果”：启动动画应直接显示，没有飞行动画。
- 开启“增强对比度”：卡片边线、玻璃输入框里的字是否仍然清楚。

## 记录格式

```
页面：对话页
控件：右下角麦克风按钮
读成：“按钮”
期望：“语音输入，按钮”
```
